# Pekora 地圖 創造服

- 核心:Paper 26.3(Docker 映像 `itzg/minecraft-server`,容器名 `mc-pekora`)
- 地圖:原 1.20.4 存檔(DataVersion 3700),2026-11-16 升到 26.3
  - 原始備份:`../zips/pekora_minecraft.zip`(**不要刪**，升級後無法再用 1.20.4 開)
  - 首次啟動時 Paper 已把資料夾結構改成 `world/dimensions/minecraft/{overworld,the_nether,the_end}`
  - 區塊是「被載入時」才轉成 26.3 格式，第一次飛到新區域會稍微卡一下
- 插件:WorldEdit 7.4.6
- 模式:創造(強制)、和平、出生點保護關閉

## 連線
- Tailscale:`100.117.80.100`(port 25565)
- 客戶端:Minecraft 26.3 + Fabric + Litematica(0.29.x)

## 常用操作
| 動作 | 指令(在 `pekora/` 資料夾) |
|---|---|
| 啟動 / 套用 compose 修改 | `docker compose up -d` |
| 停服 | `docker compose stop` |
| 重啟 | `docker compose restart` |
| 看 log | `docker logs -f mc-pekora` |
| 下伺服器指令 | `docker exec mc-pekora rcon-cli "op 玩家名"` |

## 調整過的設定
- `data/config/paper-global.yml` → `packet-limiter.all-packets.max-packet-rate: 5000`
  (預設 500;Litematica 在多人模式是用大量 /setblock /fill 指令貼建築，預設值容易被踢)

## Litematica 注意
- 用 Litematica 貼建築需要 OP。
- Paper 不能裝 Servux,所以多人模式存 schematic 時，箱子內容和部分實體可能缺。
  需要完整 NBT 時改用 WorldEdit:`//wand` 選範圍 → `//copy` → `//schem save <名稱>`,
  檔案在 `data/plugins/WorldEdit/schematics/`,Litematica 也能載入 `.schem`。
- 同台主機的生電服(`../techsmp`)用 25566/25567,不會跟本服衝突。
