# TechSMP 生電服(Fabric 26.3)

規劃依據與引用來源:`../reports/生電服 Litematica 伺服器規劃.md`
Pekora 創造服在 `../pekora`(port 25565),與本服完全獨立。
Git repo:<https://github.com/TsengJay0402/catjj-mcs>(設定、模組清單、客戶端模組包都以 repo 為準)

## 設定檔的來源(重要)
| 東西 | 以哪裡為準 | 怎麼生效 |
|---|---|---|
| 伺服器模組與版本 | `docker-compose.yml` 的 `MODRINTH_PROJECTS` | `docker compose up -d` |
| 生存服模組設定 | `config/`(掛到容器 `/config`) | 每次啟動覆蓋 `data/config` 同名檔 |
| 鏡像服模組設定 | `mirror-config/` | 同上(Servux 貼上開放所有人，其餘同生存服) |
| Carpet 規則 | `carpet.conf` | `./carpet-sync.sh push`(免重啟) |
| 客戶端模組包 | `client/mods.txt` + `client/pack.json` | 推 tag `techsmp-client-v<版本>` 後由 GitHub Actions 產生 `.mrpack`、CurseForge `.zip`,並更新 packwiz 分支 `techsmp-client-pack` |

**在遊戲內用指令改的設定(`/servux set`、`/veinminer settings`)重啟後會被 repo 蓋回去**,要保留請改 repo。
`/carpet setDefault` 改的規則請跑 `./carpet-sync.sh pull` 抄回 repo 再 commit。

## 組成
| 服務 | 容器 | Port | 用途 |
|---|---|---|---|
| 生存服 | `mc-techsmp` | **25566** | 主世界(生存、困難) |
| 創造鏡像服 | `mc-techsmp-mirror` | **25567** | 每天 05:00 從生存服同步，測機器、用 Servux 帶 NBT 快速貼投影;**改動會被覆蓋** |
| 備份 | `mc-techsmp-backup` | — | 每 3 小時快照到 `backups/`(tar.zst),保留 14 天 |

連線：依部署主機而定(部署步驟見 [`部署說明.md`](部署說明.md))。catjj 測試環境:`100.117.80.100:25566`(生存)、`:25567`(鏡像)

## 伺服器端模組(版本以 Modrinth version ID 釘死在 docker-compose.yml)

Servux 0.12.2、Syncmatica 0.3.20、Lithium 0.26.3、FerriteCore 9.0.0、Ledger 1.3.25(+Fabric Language Kotlin)、Chunky 1.5.66、
VeinMiner 2.14.0、Armored Elytra 1.16.0、squaremap 1.4.3、Flan 1.12.8.b

## Waystones (Lodeways)
- Waystone 可命名並在已知座標間傳送；距離會影響經驗消耗，另有冷卻時間。公開 Waystone 和 Warp Stone 等規則可在 `config/lodeways.json` 調整。
- 此模組新增方塊、物品和介面，玩家客戶端也必須安裝 Fabric 26.3 版 Lodeways 1.20.0。

## 背包(Backpackery)
- 分級背包，可放升級模組(整理、拾取、壓縮等),介面類似 Sophisticated Backpacks。
- 此模組新增物品和介面，**伺服器與玩家客戶端都必須安裝** Fabric 26.3 版 Backpackery 2.3.5(CurseForge 頁面標示 Client，但實際在共用端註冊物品，以 jar 內容為準)。
- **移除此模組會讓世界中所有背包物品及其內容消失**，移除或降版前先請玩家清空背包並做備份。

## 領地與領地飛行
- 生存服使用 Flan，玩家不需要安裝客戶端模組。手持金鋤頭右鍵選取領地兩個對角;木棍可檢查領地，`/flan menu` 可管理所在領地。
- 新領地主人和加入 `Co-Owner` 群組的玩家可在領地內使用創造式飛行（連按兩次跳躍）。領地以外、未受信任者與 `Visitor` 預設不能飛。
- 主人站在自己的領地內，使用 `/flan group players add Co-Owner 玩家ID` 加入共有人。**Co-Owner 權限很大，包含建造、管理領地和權限，請只授權信任的人。**
- 飛出領地會失去飛行能力，可能墜落受傷或死亡；請在接近邊界前降落。進入其他領地時，是否能飛取決於該領地的權限。
- 初始可用領地額度為 3000 格，會隨在線時間增加。Flan 預設使用三維領地，領地最低高度依選取位置設定。
- 本服的預設飛行由 `config/flan/flan_config.json` 和 `datapacks/flan-owner-flight/` 共同控制；修改、還原或升級時必須保留兩者。資料包以唯讀掛載，位於世界目錄下的掛載點內容不會包含在只備份 `data/` 的備份中，部署時須一併保留此 repo 中的資料包。

## 瀏覽器地圖
- 生存服提供 squaremap，玩家不需要安裝客戶端模組。地圖網站只綁定主機的 `127.0.0.1:18123`，不直接對其他網路開放。
- Windows 主機可用 `tailscale serve --bg --http=8123 http://127.0.0.1:18123` 分享給 tailnet，並以 `tailscale serve status` 顯示的 MagicDNS 網址存取。Tailscale 存取權限仍由 tailnet 規則控制。
- 此地圖可能顯示玩家位置及世界資訊。初次載入時，已探索區域需要時間繪製;修改本機埠可在 `.env` 設定 `MC_MAP_LOCAL_PORT`，並同步調整 Tailscale Serve 的目標。
- 若主機的 Tailscale 網址變更，請同步更新 `data/squaremap/config.yml` 的 `settings.web-address`，再執行 `docker exec mc-techsmp rcon-cli "squaremap reload"`，讓 `/map link` 使用正確網址。

## 鞘翅與胸甲
- 在鐵砧中合併鞘翅與胸甲，穿上合併後的裝備即可同時滑翔與取得胸甲防護。
- 使用砂輪可拆回原本的鞘翅與胸甲。
- 模組只需安裝在伺服器;玩家也可選擇自行安裝 [Armored Elytra](https://modrinth.com/mod/elytra-armor)，以顯示合併裝備的圖示與外觀。現有客戶端模組包不包含此模組。

## 連鎖挖礦(VeinMiner)
- **只有裝了客戶端 Hotkey 的玩家、按住快捷鍵才會觸發**(`client.require=true`,不用蹲下觸發，避免拆建築誤觸)
  - 沒裝的玩家(含原版客戶端)照樣能連線遊玩，只是不會連鎖
- 範圍：礦石(`#c:ores`,限鎬)、原木(`#minecraft:logs`,限斧),一次最多 100 格，每格扣耐久，冷卻 1 秒
- 客戶端要裝:**VeinMiner Hotkey 2.14.0 + VeinMiner 2.14.0 + Fabric Language Kotlin** + Fabric API
  - 快捷鍵預設 `Y`(或 `Z`),到「選項 → 控制」改成 `` ` ``;按住時滾輪可切換挖掘形狀，會預覽要挖的方塊
- 設定檔:`config/Veinminer/settings.json`、`groups.json`(改 repo 後 `docker compose restart mc`)
  - 想讓按住快捷鍵時可以連鎖任何方塊(像 FTB Ultimine):把 `client.allBlocks` 改成 true

## 客戶端(Minecraft 26.3 + Fabric)
完整清單和版本見 [`client/mods.txt`](client/mods.txt)。三種安裝方式擇一：

| 方式 | 啟動器 | 更新 |
|---|---|---|
| A. packwiz 自動更新(推薦) | Prism Launcher | 每次開遊戲自動檢查並安裝新版 |
| B. 匯入 `TechSMP-<版本>.mrpack` | Prism Launcher / Modrinth App | 手動下載新版重新匯入 |
| C. 匯入 `TechSMP-<版本>-curseforge.zip` | CurseForge App | 手動下載新版重新匯入 |

檔案都在 [GitHub Releases](https://github.com/TsengJay0402/catjj-mcs/releases)。

### A. Prism Launcher + packwiz(自動更新)
1. 安裝 [Prism Launcher](https://prismlauncher.org/),登入 Microsoft 帳號。
2. 「新增實例」→ 選 Minecraft **26.3** → 建立後「編輯」→「版本」→「安裝 Fabric」選 **0.20.1**。
3. 從 [packwiz-installer-bootstrap Releases](https://github.com/packwiz/packwiz-installer-bootstrap/releases) 下載 `packwiz-installer-bootstrap.jar`,放進實例的 Minecraft 資料夾(右鍵實例 →「資料夾」，裡面的 `minecraft` 或 `.minecraft`,和 `options.txt` 同一層)。
4. 「編輯」→「設定」→「自訂指令」，勾選後在「啟動前指令」貼上:
   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/TsengJay0402/catjj-mcs/techsmp-client-pack/pack.toml
   ```
5. 開啟遊戲。第一次會跳出視窗選要裝哪些選用模組(預設全不勾，選完按繼續),之後每次開遊戲都會自動更新到最新發佈版。
- 想改選用模組：刪掉 Minecraft 資料夾裡的 `packwiz.json`,下次開遊戲會重新詢問。
- 只有推發佈 tag 才會更新 `techsmp-client-pack` 分支，main 上還沒發佈的改動不會推給玩家。
- 啟動前的更新需要連網；GitHub 暫時連不上時，遊戲可能無法啟動，等一下再試。

### B. 匯入 .mrpack(Prism / Modrinth App)
下載 `TechSMP-<版本>.mrpack`,用 Modrinth App 或 Prism Launcher 匯入。
- **選用模組在兩個啟動器的行為不同**
  - Prism Launcher:匯入時跳出勾選視窗(預設全不勾，可按全選)。沒勾的會以停用狀態裝進去，之後在 Mods 頁勾起來就能用
  - Modrinth App:不會問，全部裝上並啟用。不要的到實例的 Content 頁關掉

### C. CurseForge App
1. 下載 `TechSMP-<版本>-curseforge.zip`。
2. CurseForge App →「Minecraft」→「Create Custom Profile」旁的「Import」→ 選這個 zip。
3. 選用模組會以停用狀態裝進去，要用的到設定檔的模組清單打開。
- CurseForge App 不能自動更新，新版本要重新下載 zip 匯入(會變成新的設定檔，舊的可刪掉)。
- 少數 CurseForge 上沒有相同檔案、且授權允許散佈的模組會直接附在 zip 裡；授權不允許的選用模組會被略過，需要的人自己從 Modrinth 裝。
- 建置需要 repo secret `CURSEFORGE_API_KEY`(到 <https://console.curseforge.com/> 申請)，沒設定時 Release 只會有 `.mrpack`。

### 共通說明
生存服會提供 ModernArch 4.7.2 (128x，約 255 MB) 的選用資源包下載；玩家可自行接受或拒絕。高解析材質可能增加 GPU／顯存負荷，官方未公布最低電腦規格。
硬體效能提醒由專案 agent 在討論安裝或選擇材質包時提供，不放進每次連線會顯示的伺服器提示；詳見 [`client/performance-guide.md`](client/performance-guide.md)。

## 已調整的設定
- `config/servux.json`
  - Easy Place:所有人可用(level 0,預設)
  - Servux 伺服器端貼上/任務:限 OP(level 2)(而且本來就只能在創造模式用)
  - 種子分享給所有人(MiniHUD 史萊姆區塊)、天氣、TPS/mob cap logger 開
  - `fix_allay_gathering: false`(維持原版悅靈行為)
- `config/lithium.properties`:`mixin.minimal_nonvanilla=false`(關掉 5 項非原版優化;鏡像服相同)
- `carpet.conf`:`commandPlayer true`(所有人可用 `/player` 假人)
- `pause-when-empty-seconds=0`:沒人在線也不暫停，掛機農場照跑
- 生成區塊(spawn chunks)在 1.21.9 已移除，常駐載入請用假人或 `/forceload`
- 白名單關閉，仍需正版帳號驗證;可連到伺服器的玩家皆可加入

## 升級模組 / 發布新版客戶端模組包
1. 到 Modrinth 查新的 version ID
2. 伺服器端：改 `docker-compose.yml` 的 `MODRINTH_PROJECTS`;客戶端：改 `client/mods.txt`
   (Syncmatica、VeinMiner 兩邊都有，要一起改成同版本)
3. 改 `client/pack.json` 的 `version`,在 repo 根目錄跑 `python3 tools/build-mrpack.py techsmp/client`
   (會更新 `client/modrinth.index.json` 並檢查版本和依賴)
4. commit、push,再推 tag:`git tag techsmp-client-v<version> && git push origin techsmp-client-v<version>`
   → GitHub Actions 自動建立 Release 並附上 `.mrpack`
5. `docker compose up -d` 套用伺服器端變更

## 還原備份
1. `docker compose stop mc`
2. 把 `data/world` 改名留底，只解出世界:`tar -I zstd -xf backups/<檔名>.tar.zst -C data ./world`
3. `docker compose up -d mc`
